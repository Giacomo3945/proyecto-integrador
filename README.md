# \## Descripción

# Sistema web para la gestión y coordinación de emergencias comunitarias. Permite visualizar emergencias activas, recursos disponibles, refugios habilitados, voluntarios registrados y solicitudes de asistencia.

# 

# \## Tecnologías utilizadas

# \- HTML5

# \- CSS3 (variables, Flexbox, Grid, Media Queries)

# \- Git / GitHub

# 

# \## ¿Dónde utilizamos Flexbox?

# \- \*\*Header\*\*: Para distribuir el logo y el menú de navegación horizontalmente.

# \- \*\*Estadísticas\*\*: Para distribuir los números en fila.

# \- \*\*Footer\*\*: Para organizar los enlaces de navegación.

# 

# \## ¿Dónde utilizamos Grid?

# \- \*\*Cards (Emergencias, Recursos, Refugios)\*\*: Para mostrar las tarjetas en una cuadrícula adaptable.

# \- \*\*Contacto\*\*: Para distribuir información y formulario en columnas.

# 

# \## ¿Qué variables CSS creamos?

# \- `--color-primario`: #c0392b (rojo institucional)

# \- `--color-secundario`: #2980b9 (azul de acción)

# \- `--color-fondo`: #f4f4f4 (gris claro)

# \- `--color-fondo-alt`: #ecf0f1 (gris más claro)

# \- `--color-fondo-oscuro`: #2c3e50 (gris oscuro)

# \- `--color-texto`: #333333 (gris oscuro)

# \- `--fuente-principal`: 'Segoe UI', Roboto, sans-serif

# \- `--espaciado-xs/sm/md/lg`: Espaciados estándar

# \- `--radio-borde`: 8px (bordes redondeados)

# \- `--sombra-suave/fuerte`: Sombras para tarjetas

# 

# \## ¿Cómo implementamos el Responsive Design?

# \- \*\*Media Queries\*\*:

# &#x20; - \*\*Tablet (601-1024px)\*\*: Grid de 2 columnas, menú compacto

# &#x20; - \*\*Celular (hasta 600px)\*\*: Menú vertical, Grid de 1 columna, textos más pequeños

# \- \*\*Unidades flexibles\*\*: `%`, `rem`, `vh`, `vw`, `fr`

# \- \*\*Flexbox y Grid\*\*: Layouts adaptables que se reorganizan automáticamente
